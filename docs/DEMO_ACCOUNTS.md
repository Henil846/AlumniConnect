## 6. How to Run Locally

1. Start the PHP built-in web server:
   ```powershell
   & "C:\xampp\php\php.exe" -S 127.0.0.1:8000 -t public public/index.php
   ```
2. Open your web browser at `http://127.0.0.1:8000/login`
3. Enter any demo email (e.g., `student@alumni.test` or `admin@alumni.test`) with `Password123!`

## 7. OneDrive Synchronization & SQLite File-Lock Warning

> [!WARNING]
> **OneDrive File Synchronization Hazard**
> 
> This repository is located within a Microsoft OneDrive synchronized path (`d:\OneDrive\Desktop\WT Project\Alumni-Connect-master`).
> 
> **The Problem:**
> SQLite utilizes file-level operating system locking (`flock` / `LockFileEx`) and Write-Ahead Logging (`.sqlite-wal` and `.sqlite-shm`). When OneDrive attempts to continuously sync active SQLite files in the background, file locks can conflict, leading to:
> - `SQLSTATE[HY000]: general error: database is locked`
> - Intermittent I/O transaction aborts or database corruption
> 
> **Recommended Solutions:**
> 1. **Option A (Pause Syncing):** Pause OneDrive synchronization while developing locally (`OneDrive Icon -> Pause Syncing`).
> 2. **Option B (Exclude database directory):** Right-click the `database/` folder in Windows Explorer and choose **"Always keep on this device"**, or exclude `*.sqlite*` from cloud syncing.
> 3. **Option C (Relocate Database File via .env):** Update `DB_DATABASE` in your `.env` to point to a local non-synced drive or folder:
>    ```env
>    DB_DATABASE=C:/Users/HENIL/AppData/Local/AlumniConnect/database.sqlite
>    ```
>    Alumni Connect will automatically create the directory and initialize SQLite in that non-synced location.
